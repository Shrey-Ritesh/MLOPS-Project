## Details of the data/ directory 
This directory is meant to save the DVC history, for the datasets used in the Tutor app. The actual datasets, due to size, will be stored elsewhere, details to be updated here.

## data_contract.md
The data_contract file has been developed as a part of Phase 1 - developing the solution. This file highlights the contracts that must be enforced while extracting JEE and NCERT content into JSON files. 
This file details the metadata that must be stored with each extraction, so as to ensure accurate generation of `learning units` at a later stage, which will aid in appropriate context retrieval.
